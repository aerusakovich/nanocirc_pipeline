# nanocirc: Documentation

The nanocirc documentation is split into the following pages:

- [Quick Start Guide](quickstart.md)
  - A simple-language walkthrough for your first real run: what to install, which files you need, samplesheet/config examples.
- [Usage](usage.md)
  - How to run the pipeline: samplesheet format, command-line flags, cluster/background execution.
- [Output](output.md)
  - The files and columns the pipeline produces, one output group at a time.
- [Example output](example_output/)
  - Real output files from the bundled chr21 test dataset, cross-run merge
    and quantification included, browsable without running anything.
- [Methods](methods.md)
  - How the merge algorithm, confidence scoring, cross-run merge, quantification, and type classification actually work.
- [Benchmark Results and Recommendations](benchmark.md)
  - What the four confidence tiers trade off against each other, which to use for your analysis, and the benchmark plots behind those recommendations.

You can find a lot more documentation about installing, configuring and running nf-core pipelines on the website: [https://nf-co.re](https://nf-co.re)
